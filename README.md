# 🤖 AI Solutions Development – Coding Exercises

This repository contains my learning materials, assignments, and hands-on coding exercises from the **Applied A.I. Solutions Development** graduate certificate program at **George Brown College**.

As part of my personal journey into AI and full-stack data science, this repo showcases course-by-course content, including machine learning, deep learning, mathematics, data visualization, agile project management, and more.

---

## 🎓 Program Overview

**Program**: Applied A.I. Solutions Development  
**School**: George Brown College, School of Computer Technology  
**Credential**: One-Year Postgraduate Certificate  
**Location**: Toronto, Canada  
**Delivery**: 3 semesters (including work-integrated project or co-op)  

This hands-on program blends computer science, applied mathematics, and business analysis to prepare students for careers in:

- Data Science & Analytics  
- Machine Learning / Deep Learning Engineering  
- Full-stack Data Science  
- AI Business Translation and Presentation
